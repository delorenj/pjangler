# PJAN-166 provenance and verification addendum (2026-11-19)

The Contract A sentinel choice in `PJAN-166-config-authority-trace.md` remains unchanged. The audit now parses the **whole native TOML file** and checks `[core].project_name`, rather than treating an identically named key under another table or a parseable-looking first line as proof of runtime health. The installed `resolve_config.py` is the runtime comparator. An optional custom override is not a replacement for an invalid required base TOML layer. `bmad-help.csv` is still **not** an audit sentinel: help must be read back independently after repair.
