## Project overview

- **Type:** Monolith — single npm package (CLI + MCP server + registry service)
- **Package:** `@delorenj/pjangler` v1.5.0
- **Primary language:** TypeScript (strict, ESM, Node ≥ 24)
- **Architecture:** Layered CLI with self-contained lifecycle recipes, a plan/apply execution model, and recipe-owned idempotent parity checks
- **Purpose:** Bootstrap and maintain 33GOD / DeLoNET projects — create from the CommonProject template, keep repos in parity with the 33god standard, index them centrally, scaffold subsystems, and report what an unfamiliar repo actually is

## Quick reference

- **Tech stack:** commander (CLI) · @clack/prompts (TUI) · @modelcontextprotocol/sdk (MCP) · zod · yaml · smol-toml · pg · esbuild · external `copier` (Python) · mise
- **Entry points:** `src/index.ts` (CLI: `pjangler` / `pj`), `src/mcp-server.ts` (MCP: `pjangler-mcp`), `src/prompt.ts` (`pjangler-prompt`), `src/project-registry-service.ts` (the registry service)
- **Core subsystems:** `src/recipes` + `src/commands` (composition and ownership) · `src/project` (identity, registry, bootstrap) · `src/parity` (audit/migrate primitives) · `src/notebook` (companion Open Notebook) · `src/describe` (orientation)
- **Central state:** the project registry service on `http://localhost:8764`, indexing each repo's `.project.json`
- **Board:** Plane `pjangler` (PJAN) — binding in `.project.json`

## Getting started

```bash
mise trust && npm install && mise run setup   # setup
npm run build                                  # bundle the four entry points to dist/
npm test                                       # typecheck gate, 3 package gates, 58 regression suites
node dist/index.js --help                      # explore the CLI
```

`npm test` runs `scripts/run-tests.mjs`, which typechecks first and then attempts
**every** suite — it never short-circuits on the first red one. `node scripts/run-tests.mjs --list`
prints the suite list; a filter argument runs a subset.

To work on the tool: read [Architecture](./architecture.md) → [Development Guide](./development-guide.md), and consult the **`pjangler-dev`** / **`project-jangler`** skills for the Command/Recipe authoring workflow. All code changes require a Plane ticket on board **PJAN** (see AGENTS.md).
